# Экрансыз 20 күн

Ата-энелер үчүн 20 күндүк жөнөкөй китеп жана чек-лист (кыргызча): баланы телефондон урушпай, кыргыз салтына жана ишенимге таянып, акырындык менен алыстатуу.

- Күнүнө бир тапшырма, кийинки тапшырма 24 сааттан кийин ачылат
- Мисалдар, даяр сөздөр, бата-тилектер, SOS баскычы
- Кыргыз салты жана ишеним, кибер коопсуздук тизмеси
- Прогресс колдонуучунун өз браузеринде гана сакталат (localStorage)

## Коопсуздук жана купуялык
- Статикалык сайт: сервер, аккаунт, аналитика, cookie жок
- Үчүнчү тарапка бир да сурам жок (шрифттер да сайттын өзүндө)
- Content-Security-Policy: `default-src 'none'`, скрипт жана стиль `'self'` гана
- Прогресс эч жакка жөнөтүлбөйт
